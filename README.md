# DaliMix · Dali Audio

פלאגין VST3 / AU לאבלטון לבדיקה טכנית של המיקס לפני מאסטרינג. הדוח בעברית, במבנה **בעיה → הוכחה → למה זה חשוב → מה לעשות**.

## מה חדש בגרסה 2

* **במקום ציון 0–100: סטטוס מוכנות טכנית.** "מוכן טכנית למאסטרינג" / "טוב · N נקודות לבדיקה" / "לתקן לפני מאסטרינג". הבדיקה לא שופטת את האמנותי.
* **חומרה + ביטחון** לכל ממצא, וכפתור **התעלם** לממצאים שהם החלטה אמנותית.
* **Mix Health**: שישה תחומים במבט אחד. לחיצה קופצת לפרטים.
* **ציר זמן**: זיהוי חלקים (INTRO / BUILD / BREAK / DROP / OUTRO), עקומת עוצמה, וסימון בדיוק איפה קורים צרימה, חפיפת קיק/באס, פאזה, איזון וקליפינג. **כולל מספר ה-Bar באבלטון.**
* **השמעה מתוך הפלאגין** (כשאבלטון עצור): כל ממצא או אירוע אפשר להשמיע רגיל, ב**סולו תחום** (רק תחום התדרים הבעייתי) או ב**מונו**. לחיצה על Play באבלטון עוצרת את ההשמעה.
* **חפיפת קיק/באס באחוזים**: שילוב של זמן, תדר ואנרגיה, במקום "יש/אין התנגשות". כולל אורך קיק, רמת הבאס רגע לפני מכה, ומרחק מהשורש המשוער של הטראק.
* **Headroom בלי כלל נוקשה**: אין יעד "מינוס 6". רק True Peak מעל 0 או סימני לימיטר נחשבים לבעיה.
* **רפרנס**: טעינת טראק רפרנס, טבלת השוואה שאינה תלויה בעוצמה, והשמעת A/B מותאמת עוצמה.
* **Mastering Handoff**: בדיקות טכניות אוטומטיות, רשימת נקודות לתשומת לב, והנחיות ייצוא.
* **מדדים מתקדמים** בלשונית נפרדת, כדי שהמסך הראשי יישאר נקי.

## בנייה דרך GitHub (בלי להתקין כלום)

1. מעלים את כל התיקייה ל-repository, כולל `.github/workflows/build.yml`.
2. לשונית **Actions**. הבנייה רצה אוטומטית, לוקח כ-10–15 דקות.
3. מורידים מ-**Artifacts** את `DaliMix-Windows` או `DaliMix-macOS`.

## בנייה מקומית

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

## התקנה

* Windows: `DaliMix.vst3` אל `C:\Program Files\Common Files\VST3\`
* Mac: `DaliMix.vst3` אל `~/Library/Audio/Plug-Ins/VST3/`, ו-`DaliMix.component` אל `~/Library/Audio/Plug-Ins/Components/`
* Mac, אחרי הורדה מ-GitHub:
  ```
  xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/DaliMix.vst3
  ```
* באבלטון: Preferences → Plug-Ins → Rescan

## מגבלות (בכנות)

* פלאגין VST3 לא יכול להזיז את סמן הניגון של אבלטון. לכן כל אירוע מוצג עם **Bar וזמן** בסידור, ואפשר להשמיע אותו בתוך הפלאגין.
* "מי מסתיר את מי" (למשל Lead מול Pad) דורש את הערוצים בנפרד. מתוך מיקס סטריאו זו הערכה בלבד.
* זיהוי החלקים והשורש הטונאלי הם הערכות אוטומטיות.
* ההשמעה שומרת עד 12 דקות אודיו בזיכרון (כ-140MB).
